# 华语电视

面向 Android 手机、电视和电视盒子的轻量 IPTV 播放器，使用 vbskycn/iptv 公开直播源。

## 功能

- 中文电视界面
- Android 4.0（API 14）及以上
- 支持手机触屏：点击画面显示或隐藏频道列表，上下滑动换台
- 支持遥控器方向键、确定键、菜单键和返回键
- 优先使用 vbskycn/iptv IPv4 源，加载失败时自动回退 IPv6 源
- 在线源全部失败时使用内置备用频道
- 显示直播源提供的全部频道
- 支持按频道名实时搜索
- 自动将频道源中的英文频道名翻译为中文
- 频道侧栏随手机、平板和电视屏幕宽度自动缩放
- 界面尺寸随屏幕 DPI、显示缩放及手机、平板和电视的逻辑分辨率自动适配
- 针对低高度手机横屏压缩控件间距，保留足够的视频和频道列表空间
- 支持自适应、铺满裁切、拉伸、16:9 和 4:3 画面比例，并自动记忆选择
- 自动记忆最后播放的频道，下次启动时恢复选择并播放
- 上下键换台，菜单键显示或隐藏频道列表

## 构建

```powershell
.\gradlew.bat assembleDebug
```

APK 输出到 `app\build\outputs\apk\debug\app-debug.apk`。

## 自动构建

- `Build APK`：推送到 `main` 或手动运行时构建 Debug APK，并上传为 Actions artifact。
- `Release APK`：手动运行时构建签名 Release APK，并发布到 GitHub Releases；标签留空时使用应用版本号。

## 说明

应用使用 Android 系统播放器，不同老旧电视盒子的 HLS、分辨率和视频编码支持可能不同。直播源由第三方提供，可能失效或存在地区限制，请仅观看获得合法授权的内容。
